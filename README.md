# AI WhatsApp Group Summarizer

[![CI](https://github.com/Karim3tef/AI-Whatsapp-Group-Summarizer/actions/workflows/ci.yml/badge.svg)](https://github.com/Karim3tef/AI-Whatsapp-Group-Summarizer/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
![Node.js >= 20](https://img.shields.io/badge/node-%3E%3D20-brightgreen)

بوت واتساب بيشتغل على سيرفرك (VPS) أو على جهازك. بيتابع **أي جروبات إنت تختارها** (جامعة، شغل، كورسات، عيلة، مجتمعات...)، وبيستخدم موديل AI مجاني عشان يطلّعلك المهم بس (مواعيد، ديدلاينز، تغييرات، قرارات، إعلانات)، وبيبعتهولك على شات **"رسالة لنفسك"** في واتساب:

- 🕘 **ملخص مجدول** في الميعاد اللي تحدده، أو
- ⚡ **تنبيه فوري** أول ما رسالة مهمة تظهر، أو **الاتنين مع بعض**.

ولو عايز تربطه بمشروع تاني أو داشبورد، فيه **API آمن بمفاتيح** و **Webhooks موقّعة** (اختياري).

## 💡 الفكرة

جروبات الواتساب بيبقى فيها مئات الرسايل في اليوم، أغلبها هزار وأسئلة مكررة، ووسطها معلومة مهمة زي ميعاد اتغير أو حاجة مطلوبة منك قبل بكرة، وممكن تضيع.

البوت بيقرا الجروبات اللي **إنت** تختارها بس، وبيطلّع منها المهم بالـ AI، وبيبعتهولك.

### البدائل اللي اتدرست
| الطريقة | المميزات | العيوب |
|---|---|---|
| ميزة Message Summaries في واتساب (Meta AI) | جاهزة ومن غير مجهود | بدأت بالإنجليزي في أمريكا، وممكن متكونش متاحة بالعربي في بلدك |
| Export chat يدوي وتلخيصه بأي AI | سهلة ومضمونة | يدوية ومش أوتوماتيك |
| **المشروع ده** | أوتوماتيك، مجاني، فوري أو مجدول، وليه API | محتاج سيرفر أو جهاز شغال، وطريقة غير رسمية |
| n8n | واجهة سحب وإفلات | مش هيبسّط حاجة، لأنه برضو محتاج نفس مكتبة الواتساب في النص |

> ⚠️ **تحذير:** البوت بيستخدم مكتبة غير رسمية ([whatsapp-web.js](https://github.com/pedroslopez/whatsapp-web.js))، وده مخالف لشروط واتساب. فيه احتمال صغير إن الرقم يتحظر. البوت بيقرا بس وبيبعت رسايل قليلة لنفسك، وده بيقلل الخطر بس مش بيلغيه. استخدامك ليه على مسؤوليتك.

## ✨ المميزات

**الأساس**
- 📥 بيتابع الجروبات اللي تختارها بس، والباقي بيتجاهله.
- 📱 اختيار الجروبات من الواتساب نفسه بالأرقام (`!جروبات` ثم `!تابع 3`)، أو من الـ API، أو من `.env`.
- 🔄 لو جروب اتغير اسمه، البوت بيفضل متابعه (بيتعرف عليه بالـ ID).
- 💬 كل حاجة بتوصلك على شات **"رسالة لنفسك"** (وتقدر تقفلها لو عايز الـ API بس).

**التلخيص والتنبيهات**
- 🕘 **وضع مجدول**: ملخص في ميعاد ثابت (cron) بأي توقيت.
- ⚡ **وضع فوري**: تنبيه أول ما رسالة مهمة توصل، والـ AI هو اللي بيقرر إيه المهم.
- 🔀 **الاتنين مع بعض**، والتغيير في أي وقت بـ `!وضع` من غير restart.
- 🌙 **ساعات هدوء**: التنبيهات بتستنى لحد الصبح وتوصلك مرة واحدة (والعاجل ممكن يعدي).
- 🔔 تنبيه بالكلمات (من غير AI) لكلمات زي "امتحان" و "اتلغت".
- ✂️ تقسيم الرسايل الكتير لأجزاء عشان حدود المزود المجاني، ودمج الملخصات.
- 🔁 إعادة محاولة أوتوماتيك لو المزود قال `429` أو وقع مؤقتًا.

**الربط والأمان**
- 🔌 **REST API** بمفاتيح: الملخصات، التنبيهات، الجروبات، الإعدادات، وطلب ملخص.
- 📡 **بث مباشر (SSE)** للداشبورد عشان يتحدث لوحده.
- 🪝 **Webhooks موقّعة بـ HMAC** بتبعت كل ملخص أو تنبيه جديد لمشروعك.
- 🔐 تشفير ملفات البيانات بـ **AES-256-GCM**، وملفات بصلاحيات `600`.
- 🛡️ الـ API على `127.0.0.1` افتراضيًا، rate limit، قفل بعد محاولات غلط، والرسايل الخام مقفولة افتراضيًا.
- 🧙 **معالج إعداد** (`npm run setup`) بيعمل `.env` وبيولّد كل المفاتيح.
- 🐳 تشغيل بـ pm2 أو Docker، و 84 اختبار و CI.

## 🔀 الأوضاع: مجدول ولا فوري؟

| الوضع | بيعمل إيه | مناسب لـ |
|---|---|---|
| **مجدول** (`schedule`) | ملخص واحد في الميعاد (مثلًا 9 بالليل) | لو عايز تقرا مرة في اليوم ومش عايز إزعاج |
| **فوري** (`realtime`) | أول ما رسالة مهمة توصل، بيبعتلك تنبيه | لو المواعيد بتتغير بسرعة ومحتاج تعرف على طول |
| **الاتنين** (`both`) | تنبيهات فورية + ملخص اليوم | أقوى تغطية |

**إزاي الوضع الفوري بيوفر الكوتا المجانية؟** البوت مش بيسأل الـ AI عن كل رسالة. بيستنى لحد ما الجروب يهدى دقيقتين (`REALTIME_DEBOUNCE`)، وبحد أقصى 10 دقايق من أول رسالة (`REALTIME_MAX_WAIT`)، وبعدين بيبعت الرسايل الجديدة كلها في طلب واحد. الـ AI بيرد بالمهم بس، ولو مفيش حاجة مهمة مش بيبعتلك حاجة.

غيّر الوضع من الواتساب في أي وقت:
```
!وضع فوري
!وضع مجدول
!وضع الاتنين
```

> في كل الأوضاع، الرسايل بتتجمع برضو، فـ `!ملخص` شغال دايمًا.

## ⚙️ طريقة العمل

```
┌─────────────┐     ┌────────────────────────────────────────┐     ┌──────────────┐
│  واتساب     │     │            السيرفر أو جهازك             │     │  مزود الـ AI │
│ (موبايلك)   │◄───►│ 1. whatsapp-web.js (واتساب ويب مخفي)   │     │ Groq أو      │
│ Linked      │     │ 2. فلترة: الجروبات المتابعة بس          │     │ OpenRouter أو│
│ device      │     │ 3. حفظ آمن في data/ (اختياري: مشفر)    │     │ Ollama       │
│             │     │ 4. مجدول: node-cron  │ فوري: دفعات صغيرة │────►│ 5. التلخيص / │
│ "رسالة      │◄────│ 6. إرسال لنفسك (مع ساعات الهدوء)        │◄────│    الفرز     │
│  لنفسك"     │     │ 7. حفظ في السجل ومسح الرسايل المتلخصة   │     └──────────────┘
└─────────────┘     │ 8. (اختياري) API / بث مباشر / Webhook   │────► مشروعك / الداشبورد
                    └────────────────────────────────────────┘
```

1. **الربط:** البوت بيفتح واتساب ويب في متصفح Chromium مخفي، وبتربطه بـ QR code زي أي جهاز مربوط. الجلسة بتتحفظ في `.wwebjs_auth` عشان ما تعملش scan كل مرة.
2. **الفلترة:** كل رسالة جديدة بيتأكد إنها من جروب في قايمة المتابعة.
3. **الحفظ:** بتتحفظ في `data/messages.json` بطريقة آمنة (ملف مؤقت ثم rename، وصلاحية `600`، ومشفرة لو فعّلت التشفير). لو البوت عمل restart مفيش حاجة بتضيع.
4. **التوقيت:** في الوضع المجدول `node-cron` بيشغّل التلخيص في ميعادك. في الوضع الفوري الرسايل بتتجمع في دفعات صغيرة وتتفحص.
5. **الـ AI:** الملخص بيتقسم لأجزاء لو كبير وبعدين يتدمج. التنبيهات الفورية الـ AI بيرد فيها بـ JSON فيه المهم بس.
6. **الإرسال:** على "رسالة لنفسك". التنبيهات وقت الهدوء بتستنى.
7. **التنظيف:** بعد النجاح بس، الرسايل اللي اتلخصت بتتمسح. لو حصل خطأ كل حاجة بتفضل للمرة الجاية.
8. **النشر (اختياري):** الملخص أو التنبيه بيتحفظ في السجل، وبيوصل للـ API والبث المباشر والـ Webhook.

تفاصيل تقنية: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## 💬 أوامر الواتساب

بتتبعت في شات **"رسالة لنفسك"** بس. لو حد تاني بعتها في جروب مش هيحصل حاجة.

| الأمر | بالإنجليزي | الوظيفة |
|---|---|---|
| `!ملخص` | `!summary` | ملخص فوري للرسايل المتجمعة |
| `!جروبات` | `!groups` | كل جروباتك بأرقام، و ✅ جنب المتابَعة |
| `!تابع <رقم أو اسم>` | `!watch` | ابدأ تتابع جروب. مثال: `!تابع 3` أو `!تابع شغل` |
| `!الغي <رقم أو اسم>` | `!unwatch` | وقف متابعة جروب (`!إلغاء` شغالة كمان) |
| `!متابعة` | `!watching` | الجروبات المتابَعة بس |
| `!وضع [مجدول/فوري/الاتنين]` | `!mode` | يعرض أو يغيّر الوضع |
| `!تنبيهات` | `!alerts` | آخر التنبيهات الفورية |
| `!حالة` | `!status` | الوضع، الرسايل المستنية، الملخص الجاي، آخر ملخص، الموديل |
| `!مسح` | `!clear` | مسح الرسايل المستنية من غير تلخيص |
| `!مساعدة` | `!help` | قايمة الأوامر |

> الأرقام هي نفس أرقام `!جروبات`. ولو كتبت جزء من الاسم وكان فيه جروب واحد بس بيطابقه، هيتختار.

## 🤖 اختيار مزود الـ AI

الكود شغال مع أي API متوافق مع OpenAI، والتبديل من `.env` بس.

| | **Groq** ⭐ (مرشح) | **OpenRouter (`:free`)** | **Ollama (محلي)** |
|---|---|---|---|
| السعر | مجاني | مجاني | مجاني |
| التدريب على البيانات | مكتوب إنه مش بيدرب | حسب السيرفر. **لازم تقفل التدريب من Privacy settings** | مفيش، كله عندك |
| الحدود | حد tokens صغير في الدقيقة | حوالي 50 طلب في اليوم و 20 في الدقيقة | على قد الجهاز |
| الثبات | ثابت | الموديلات المجانية بتتغير | ثابت |
| الرام | — | — | 8 جيجا أو أكتر |

> مع Groq و OpenRouter الرسايل **بتوصل لسيرفراتهم** عشان تتلخص. Ollama هو الوحيد اللي مفيش فيه أي رسالة بتخرج.

> الوضع الفوري بيستهلك طلبات أكتر من المجدول (طلب لكل دفعة). مع OpenRouter (50 طلب/يوم) خلي `REALTIME_DEBOUNCE` أكبر، أو استخدم Groq.

> الحدود والسياسات بتتغير، راجع صفحات المزودين الرسمية.

## 🔒 الخصوصية: مين بيشوف إيه؟

| الطرف | بيوصل لإيه |
|---|---|
| **البوت (الكود عندك)** | مربوط بالواتساب، فنظريًا يقدر يوصل لكل حاجة، بس بيعمل اللي في الكود بس. الكود مفتوح وتقدر تراجعه |

## 🛠️ التثبيت على سيرفر (VPS)

### 1) تجهيز السيرفر
```bash
ssh root@IP_السيرفر
```
```bash
apt update && apt upgrade -y
```
يوزر منفصل للبوت (أأمن من الـ root):
```bash
adduser bot
usermod -aG sudo bot
su - bot
```

### 2) تنزيل المشروع وتثبيته
```bash
sudo apt install -y git
git clone https://github.com/Karim3tef/AI-Whatsapp-Group-Summarizer.git
cd AI-Whatsapp-Group-Summarizer
bash scripts/setup-server.sh
```
السكريبت بيثبت Node.js ومكتبات Chromium و pm2 ومكتبات المشروع، وبعدين بيشغّل **معالج الإعداد**.

<details>
<summary><b>أو التثبيت يدوي</b></summary>

```bash
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt install -y nodejs
sudo apt install -y libnss3 libatk1.0-0 libatk-bridge2.0-0 libcups2 libdrm2 \
  libxkbcommon0 libxcomposite1 libxdamage1 libxrandr2 libgbm1 libpango-1.0-0 \
  libcairo2 libasound2 fonts-noto-core
# على Ubuntu 24.04 بدّل libasound2 بـ libasound2t64 لو طلّع error
sudo npm install -g pm2
npm ci --omit=dev
npm run setup
```
</details>

### 3) معالج الإعداد (`npm run setup`)
بيسألك أسئلة بسيطة وبيكتب `.env` بصلاحية `600`:
- مزود الـ AI والمفتاح والموديل.
- الوضع (مجدول / فوري / الاتنين)، ميعاد الملخص، التوقيت، ساعات الهدوء.
- تبعت على "رسالة لنفسك" ولا لأ.
- تشفير ملفات البيانات (**بيولّد المفتاح**).
- تفعيل الـ API (**بيولّد API key**) و Webhook (**بيولّد السر**).

في الآخر بيطبعلك بيانات الربط (العنوان والمفتاح) عشان تحطها في مشروعك.

<details>
<summary><b>أو اعمل <code>.env</code> بإيدك</b></summary>

```bash
cp .env.example .env
nano .env
chmod 600 .env
```
كل الاختيارات متشرحة جوه `.env.example`. لتوليد أي مفتاح: `npm run secret`.
</details>

### 4) أول تشغيل وربط الواتساب واختيار الجروبات
```bash
npm start
```
1. هيظهر **QR code** (لو مش باين كامل، كبّر الشباك أو صغّر الخط).
2. من الموبايل: واتساب ← **Linked devices** ← **Link a device**، واعمل scan.
3. استنى `✅ WhatsApp connected`.
4. في شات **"رسالة لنفسك"** ابعت `!جروبات`.
5. اختار الجروبات بالرقم: `!تابع 3`، `!تابع 7`...
6. اتأكد بـ `!متابعة`، وجرّب `!حالة` و `!ملخص`.
7. اقفل بـ `Ctrl+C`.

> `!تابع` و `!الغي` و `!وضع` بيتطبقوا على طول ومن غير restart.

### 5) التشغيل الدائم بـ pm2
```bash
pm2 start ecosystem.config.js
pm2 save
pm2 startup
```
> `pm2 startup` هيطبع سطر بيبدأ بـ `sudo`. نفّذه زي ما هو عشان البوت يشتغل لوحده بعد restart السيرفر.

اسم البوت في pm2: `ai-whatsapp-group-summarizer`.

## 🐳 التشغيل بـ Docker

مش محتاج Node ولا مكتبات Chromium:
```bash
npm run setup          # أو: cp .env.example .env && nano .env
docker compose up -d --build
docker compose logs -f # اعمل scan للـ QR، وبعدين Ctrl+C
```
- الجلسة والبيانات في Docker volumes (`wwebjs_auth` و `data`).
- الكونتينر شغال بيوزر عادي (مش root)، ومن غير صلاحيات زيادة.
- لو فعّلت الـ API، هيبقى على `127.0.0.1:3000` في السيرفر بس.

| الأمر | الوظيفة |
|---|---|
| `docker compose logs -f` | اللوجز |
| `docker compose restart` | بعد تعديل `.env` |
| `git pull && docker compose up -d --build` | تحديث |
| `docker compose down` | إيقاف |

## 🔌 الربط بمشروع تاني أو داشبورد (API و Webhooks)

**ده اختياري.** "رسالة لنفسك" بتفضل شغالة عادي. فعّل الـ API لو عايز تعرض الملخصات والتنبيهات في داشبورد أو تتحكم في البوت من مشروع تاني.

### الـ API
في `.env` (أو من معالج الإعداد):
```env
API_ENABLED=true
API_HOST=127.0.0.1
API_PORT=3000
API_KEYS=المفتاح_اللي_اتولد
```
كل طلب لازم يكون فيه المفتاح:
```bash
curl http://127.0.0.1:3000/v1/summaries/latest -H "Authorization: Bearer API_KEY"
```

| اللي عايزه | الطلب |
|---|---|
| آخر ملخص | `GET /v1/summaries/latest` |
| سجل الملخصات | `GET /v1/summaries?limit=10` |
| التنبيهات الفورية | `GET /v1/alerts` |
| تحديث مباشر للداشبورد | `GET /v1/stream` (Server-Sent Events) |
| اعمل ملخص دلوقتي | `POST /v1/summaries` (`{"deliver": false}` عشان ميتبعتش واتساب) |
| الجروبات وتابع/الغي | `GET /v1/groups` ، `POST /v1/groups/watched` ، `DELETE /v1/groups/watched/{id}` |
| غيّر الوضع | `PATCH /v1/settings` بـ `{"mode": "realtime"}` |
| حالة البوت | `GET /v1/status` |

### Webhooks
عايز البوت هو اللي **يبعت** لمشروعك أول ما يطلع ملخص أو تنبيه:
```env
WEBHOOK_URL=https://your-app.com/hooks/whatsapp-summary
WEBHOOK_SECRET=السر_اللي_اتولد
```
كل طلب موقّع بـ HMAC-SHA256، ومشروعك لازم يتأكد من التوقيع قبل ما يصدّق البيانات.

📘 **التوثيق الكامل** (كل الطلبات، الردود، الأخطاء، التحقق من التوقيع بـ Node و Python، وإزاي تفتح الـ API للإنترنت بـ HTTPS بأمان): [docs/API.md](docs/API.md)

🧩 **أمثلة جاهزة:** [examples/api-client.js](examples/api-client.js) (يقرا الملخصات ويستقبل البث المباشر) و [examples/webhook-receiver.js](examples/webhook-receiver.js) (يستقبل الـ webhooks ويتحقق منها).

> ⚠️ متحطش الـ API key في كود الـ frontend (المتصفح). خلي الـ backend بتاع الداشبورد هو اللي يكلم الـ API.

## ⚙️ كل الإعدادات (`.env`)

**الـ AI**
| المتغير | افتراضي | المعنى |
|---|---|---|
| `AI_URL` | مطلوب | عنوان chat completions بتاع المزود |
| `AI_KEY` | مطلوب | المفتاح (مع Ollama أي كلمة) |
| `AI_MODEL` | مطلوب | اسم الموديل |
| `CHUNK_SIZE` | `8000` | أقصى حروف في الجزء الواحد |
| `CHUNK_WAIT` | `60000` | انتظار بين الأجزاء (ms) |
| `AI_MAX_RETRIES` | `3` | إعادة المحاولة لو `429` أو `5xx` |
| `AI_TIMEOUT` | `120000` | أقصى وقت للطلب (ms) |

**الوضع والمواعيد**
| المتغير | افتراضي | المعنى |
|---|---|---|
| `MODE` | `schedule` | `schedule` أو `realtime` أو `both` (بيتغير بـ `!وضع`) |
| `SCHEDULE` | `0 21 * * *` | ميعاد الملخص بصيغة cron |
| `TIMEZONE` | `Africa/Cairo` | التوقيت (أي اسم IANA) |
| `REALTIME_DEBOUNCE` | `120000` | الوضع الفوري: يستنى الجروب يهدى المدة دي (ms) |
| `REALTIME_MAX_WAIT` | `600000` | الوضع الفوري: أقصى انتظار من أول رسالة (ms) |
| `QUIET_HOURS` | فاضي | ساعات هدوء للتنبيهات، مثلًا `23:00-07:00` |
| `QUIET_HOURS_ALLOW_URGENT` | `true` | العاجل يعدّي في ساعات الهدوء |
| `DELIVER_TO_WHATSAPP` | `true` | يبعت على "رسالة لنفسك" |
| `URGENT_KEYWORDS` | فاضي | كلمات مفصولة بـ `,` تتبعت فورًا من غير AI |
| `GROUPS` | فاضي | أسماء جروبات مفصولة بـ `\|` (أول تشغيل بس) |

**البيانات والأمان**
| المتغير | افتراضي | المعنى |
|---|---|---|
| `DATA_ENCRYPTION_KEY` | فاضي | تشفير ملفات `data/` (64 حرف hex). **احتفظ بنسخة منه** |
| `SUMMARY_HISTORY` | `30` | عدد الملخصات المحفوظة للـ API (`0` = ولا واحد) |
| `ALERT_HISTORY` | `100` | عدد التنبيهات المحفوظة |
| `MAX_STORED_MESSAGES` | `5000` | أقصى رسايل مستنية |
| `DATA_DIR` / `AUTH_DIR` | `data` / `.wwebjs_auth` | أماكن الملفات |

**الـ API و Webhooks**
| المتغير | افتراضي | المعنى |
|---|---|---|
| `API_ENABLED` | `false` | تشغيل الـ API |
| `API_HOST` / `API_PORT` | `127.0.0.1` / `3000` | العنوان والبورت |
| `API_KEYS` | فاضي | مفاتيح مفصولة بـ `,` (32 حرف على الأقل) |
| `API_RATE_LIMIT` | `60` | طلبات في الدقيقة لكل IP |
| `API_TRUST_PROXY` | `false` | `true` بس ورا reverse proxy |
| `API_CORS_ORIGINS` | فاضي | مواقع مسموح لها من المتصفح |
| `API_ALLOW_RAW_MESSAGES` | `false` | السماح بقراية نص الرسايل الخام |
| `WEBHOOK_URL` / `WEBHOOK_SECRET` | فاضي | عنوان الـ webhook (https) والسر |

**متقدم:** `PROMPT_FILE`، `REALTIME_PROMPT_FILE`، `PUPPETEER_EXECUTABLE_PATH`.

> لو فيه إعداد غلط، البوت مش هيشتغل وهيطبعلك **كل** المشاكل مرة واحدة.

## 🔐 الأمان
- فولدر **`.wwebjs_auth`** هو مفتاح حسابك. **محدش غيرك يوصله** ومترفعهوش على GitHub (موجود في `.gitignore`).
- `.env` بصلاحية `600`، وملفات `data/` بتتعمل بصلاحية `600` لوحدها.
- فعّل **`DATA_ENCRYPTION_KEY`** عشان الرسايل والملخصات تتشفر على الديسك.
- الـ API مقفول افتراضيًا، ولما يتفعل بيبقى على الجهاز نفسه بس. لو هتفتحه للإنترنت: **HTTPS ورا reverse proxy** ([الطريقة](docs/API.md#exposing-the-api-safely)).
- ادخل السيرفر بـ **SSH key** بدل الباسورد، وفعّل الـ firewall:
  ```bash
  sudo ufw allow OpenSSH
  sudo ufw enable
  ```
- راجع **Linked devices** في الموبايل كل فترة. ولو عايز توقف كل حاجة فورًا: **Log out** للجهاز.

كل التفاصيل في [SECURITY.md](SECURITY.md).

## 🧯 حل المشاكل

| المشكلة | الحل |
|---|---|
| `Invalid configuration` | البوت بيقولك بالظبط إيه الغلط في `.env`. صلّحه وشغّل تاني |
| `error while loading shared libraries` | مكتبات Chromium ناقصة: `bash scripts/setup-server.sh` |
| الـ QR مش ظاهر كامل | كبّر الشباك أو صغّر الخط |
| الأوامر مش بترد | لازم تتبعت في **"رسالة لنفسك"** وتبدأ بـ `!` |
| جروب رسايله مش بتتسجل | `!جروبات` واتأكد إن جنبه ✅، لو لأ `!تابع رقمه` |
| رسايلك إنت مش بتتسجل | مقصود: البوت بيلخص رسايل الناس التانية |
| الوضع الفوري مش بيبعت حاجة | اتأكد بـ `!وضع`، واستنى `REALTIME_DEBOUNCE`. ولو الـ AI شايف إن مفيش حاجة مهمة مش هيبعت. شوف `pm2 logs` (`Real-time check`) |
| تنبيهات كتير | زوّد `REALTIME_DEBOUNCE`، أو اكتب تعليمات أشد في `REALTIME_PROMPT_FILE` |
| `401` من الـ AI | `AI_KEY` غلط |
| `429` من الـ AI | البوت بيعيد لوحده. لو فضل: صغّر `CHUNK_SIZE` أو كبّر `CHUNK_WAIT` / `REALTIME_DEBOUNCE` |
| OpenRouter بيقول مفيش endpoints | إعدادات الخصوصية منعت السيرفرات. اختار موديل free تاني |
| `401` من الـ API | المفتاح مش موجود في `API_KEYS` أو الـ header غلط |
| `could not be decrypted` | `DATA_ENCRYPTION_KEY` اتغير. رجّع القديم |
| البوت وقف فجأة | غالبًا واتساب ويب اتحدث: `npm update whatsapp-web.js` ثم `pm2 restart ai-whatsapp-group-summarizer` |
| بيطلب QR تاني | `pm2 stop ai-whatsapp-group-summarizer` ← `rm -rf .wwebjs_auth` ← `npm start` واعمل scan ← `Ctrl+C` ← `pm2 restart ai-whatsapp-group-summarizer` |

> بعد أي تعديل راجع `pm2 logs ai-whatsapp-group-summarizer`.

## 🧩 تخصيص

**ملخص مرتين في اليوم:** `SCHEDULE=0 8,21 * * *`

**ما عدا الجمعة:** `SCHEDULE=0 21 * * 0-4,6`

**تعليمات خاصة بيك:** اكتب ملف `prompt.txt` (مثلًا "ركز على مواعيد التسليم"، "اكتب بالإنجليزي") وحط `PROMPT_FILE=prompt.txt`. وللوضع الفوري `REALTIME_PROMPT_FILE` (لازم تفضل تطلب نفس شكل الـ JSON). التعليمات الافتراضية في [src/prompt.js](src/prompt.js).

**API بس من غير واتساب:** `DELIVER_TO_WHATSAPP=false` (أو `PATCH /v1/settings`).

**تغيير المزود:** عدّل `.env` ثم `pm2 restart ai-whatsapp-group-summarizer`.
